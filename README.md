# AgriShare

An agricultural resource sharing network and marketplace platform connecting farmers, equipment owners, and input suppliers. Rent what you need, buy only what you must own.

View your app in AI Studio: https://ai.studio/apps/95825152-9741-46f8-bbf0-02d750828223

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   `npm install`
2. Configure `.env` with Firebase and Gemini keys (pre-configured)
3. Run the development server:
   `npm run dev`
